# Рейсы Новосибирск–Барнаул

## Живое расписание (API Яндекс.Расписаний) на Mac
1. Получите бесплатный ключ API Яндекс.Расписаний в кабинете разработчика Яндекса.
2. В папке `app` скопируйте `.env.example` в `.env` и впишите ключ: `YANDEX_RASP_KEY=ваш_ключ`.
   Файл `.env` в git не попадает. Ключ никому не отправляйте и не вставляйте в чат.
3. В Терминале: `python3 app/server.py`, затем откройте http://localhost:8000

Без ключа или без сервера приложение показывает демо-данные (сверху пометка «Демо-данные»).

## Только посмотреть
Двойной клик по `app/index.html`: всё в одном файле, данные демонстрационные.

## Правки
`index.src.html` (дизайн, логика), `data.js` (демо-рейсы, адреса, ссылки), `server.py` (API).
После правок: `python3 app/build.py`.
Коды городов Яндекса: Новосибирск `c65`, Барнаул `c197` (можно переопределить через CODE_NSK / CODE_BRN).
